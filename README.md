A REST API for managing **programming languages** and the **technologies** built on them (for example *Java → Spring*, *C# → ASP.NET*). Built with **Spring Boot 3** and PostgreSQL as homework for the [Kodlama.io](https://www.kodlama.io) Java & React bootcamp (weeks 5–7).

The project applies a layered architecture with request/response DTOs, ModelMapper, business rules and centralised exception handling.

---

## Features

- CRUD endpoints for languages and technologies
- One-to-many relationship: each technology belongs to a language
- **Business rules**: duplicate language or technology names are rejected
- **Validation**: names must be 3–20 characters and not blank (`@NotBlank`, `@Size`)
- **Global exception handling** with `@RestControllerAdvice`, returning `ProblemDetails` for business errors and `ValidationProblemDetails` with field errors for invalid input
- **DTO mapping** with ModelMapper, so entities are never exposed directly
- **Swagger UI** generated by springdoc-openapi

## Architecture

```
webApi/controllers      ──►  LanguagesController, TechnologiesController
        │
business/abstracts      ──►  LanguageService, TechnologyService (interfaces)
business/concretes      ──►  LanguageManager, TechnologyManager
business/rules          ──►  LanguageBusinessRules, TechnologyBusinessRules
business/requests       ──►  Create/Update request DTOs (validated)
business/responses      ──►  GetAll / GetById response DTOs
        │
dataAccess/abstracts    ──►  LanguageRepository, TechnologyRepository (Spring Data JPA)
        │
entities/concretes      ──►  Language 1 ── * Technology
        │
core/utilities          ──►  ModelMapper service, BusinessException, ProblemDetails
```

## API

Base URL: `http://localhost:8080`

### Languages

| Method | Endpoint | Body | Description |
|---|---|---|---|
| `GET` | `/api/languages` | — | All languages |
| `GET` | `/api/languages/{id}` | — | A language by ID |
| `POST` | `/api/languages` | `{ "name": "Java" }` | Create a language (`201 Created`) |
| `PUT` | `/api/languages` | `{ "id": 1, "name": "Java" }` | Update a language |
| `DELETE` | `/api/languages/{id}` | — | Delete a language |

### Technologies

| Method | Endpoint | Body | Description |
|---|---|---|---|
| `GET` | `/api/technologies` | — | All technologies with their language name |
| `GET` | `/api/technologies/{id}` | — | A technology by ID |
| `POST` | `/api/technologies` | `{ "name": "Spring", "languageId": 1 }` | Create a technology (`201 Created`) |
| `PUT` | `/api/technologies` | `{ "id": 1, "name": "Spring Boot", "languageId": 1 }` | Update a technology |
| `DELETE` | `/api/technologies/{id}` | — | Delete a technology |

### Error responses

```json
// Business rule violation (400)
{ "message": "Language already exists" }

// Validation error (400)
{
  "message": "VALIDATION.EXCEPTION",
  "validationErrors": { "name": "size must be between 3 and 20" }
}
```

Interactive documentation is available at **http://localhost:8080/swagger-ui/index.html** while the app is running.

## Getting started

### Prerequisites

- JDK 17
- PostgreSQL

### Setup

1. Create the database:

   ```sql
   CREATE DATABASE "homeworkDb";
   ```

2. Configure the database connection. The password is read from an environment variable rather than stored in the repository. For local development:

   ```bash
   cd Kodlama.io.Devs
   cp .env.example .env
   ```

   and set `DB_PASSWORD` in `.env` (it is git-ignored and loaded automatically).

   | Variable | Required | Default |
   |---|---|---|
   | `DB_PASSWORD` | ✅ | — |
   | `DB_URL` | | `jdbc:postgresql://localhost:5432/homeworkDb` |
   | `DB_USERNAME` | | `postgres` |

3. Run:

   ```bash
   ./mvnw spring-boot:run        # Windows: mvnw.cmd spring-boot:run
   ```

Tables are created automatically on startup (`ddl-auto=update`).
